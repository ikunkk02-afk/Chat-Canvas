Chat Canvas 1.2.0 for Minecraft 1.21.9 (Fabric)

## 版本信息
- **Minecraft**: 1.21.9
- **Loader**: Fabric 0.19.3+
- **Fabric API**: 0.134.1+1.21.9
- **owo-lib**: 0.12.24+1.21.9
- **Mod Menu**: 16.0.1+ (可选)
- **Java**: 21+

## 移植说明
从 mc/1.21.8 基线移植至 Minecraft 1.21.9 (Fabric)。

### 主要适配变更
- **输入 API 重构**: MC 1.21.9 引入了 `KeyInput`/`CharInput`/`Click` 包装类型替代原始参数
- **Keyboard.onKey**: `(long,int,int,int,int)` → `(long,int,KeyInput)`，可见性 `public`→`private`
- **GameProfile**: `getName()`/`getId()` → `name()`/`id()` (record 访问器)
- **DrawContext.drawBorder**: 移除，使用 fill 实现替代
- **TextRenderer**: `getFontStorage()`/`FontStorage` 字体 API 完全重构，使用 `getWidth()` 替代
- **TextFieldWidget**: `renderTextProvider` 字段移除，替换为 `formatters` 列表

### 依赖版本
- Fabric Loader: 0.19.3
- Fabric API: 0.134.1+1.21.9
- owo-lib: 0.12.24+1.21.9
- Mod Menu: 16.0.1
- Fabric Loom: 1.17.17
- Yarn mappings: 1.21.9+build.1

## 安装
1. 下载 `chat-canvas-1.2.0.jar`
2. 放入 `.minecraft/mods/` 目录
3. 确保已安装 Fabric Loader 0.19.3+、Fabric API 和 owo-lib
4. 启动 Minecraft 1.21.9 Fabric
