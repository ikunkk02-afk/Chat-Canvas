# Chat Canvas 1.2.0 for Minecraft 1.21.8

A visual and highly customizable client-side chat HUD editor for Minecraft Fabric.

## What's New in This Port

- Ported from Minecraft 1.21.1 baseline to 1.21.8 (via mc/1.21.6).
- Updated dependency versions for full 1.21.8 compatibility.
- Replaced `TextFieldWidget.drawSelectionHighlight` (removed in MC 1.21.7) with `DrawContext.drawSelection()`.

## Dependencies

- Minecraft 1.21.8 (client-only)
- Fabric Loader >=0.19.3
- Fabric API >=0.136.1
- owo-lib >=0.12.23
- ModMenu >=15.0.2 (optional, for settings screen)

## Installation

1. Install Fabric Loader for Minecraft 1.21.8
2. Install Fabric API
3. Install owo-lib
4. Copy `chat-canvas-1.2.0+1.21.8.jar` to your `mods/` folder

## All Features (27 features retained)

1. Split player/command chat channels
2. Independent player/command input fields
3. Auto-switch to command mode on `/`
4. Separate chat/command history
5. Command tool panel
6. Recent commands
7. Favorited commands
8. System clipboard command candidates
9. Classic chat layout
10. Left-right split layout (current player right-aligned)
11. Auto word wrapping
12. Font size, character spacing, line spacing, opacity settings
13. Double-click player name to @mention
14. @mention notifications
15. Unicode emoji input
16. Emoji search, categories, recently used
17. Unicode grapheme cluster cursor/deletion
18. Vosk offline Chinese speech-to-text
19. Mouse hold-to-talk
20. Customizable keyboard hold-to-talk
21. Chinese voice encoding fix
22. Microphone concurrent release fix
23. Local chat log saving (JSONL)
24. Config compatibility + corruption fallback
25. Vanilla chat safety fallback
26. Client-only (no server install required)
27. Compatible with chat rendering mods
