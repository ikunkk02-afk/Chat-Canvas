# Chat Canvas 1.2.0 for Minecraft 1.21.4

A visual and highly customizable client-side chat HUD editor for Minecraft.

## What's New in This Port

- **Minecraft 1.21.4 support**: All features from the 1.21.1 version have been ported
- Updated dependencies: Fabric Loader 0.19.3, Fabric API 0.119.4+1.21.4, owo-lib 0.12.20+1.21.4
- Two API adaptations: `DrawContext.drawTextWrapped` → `drawWrappedTextWithShadow`, `ChatHud.getMessageLineIndex` → `getMessageIndex`
- All 15 Mixins verified compatible via source-level audit and `runClient` test

## Features (unchanged from 1.2.0)

- Dual chat channels: player chat + command/system
- Independent player/command input fields with mode switching
- Split alignment layout (own messages right, others left)
- Unicode emoji input with search, categories, and recent
- Vosk offline Chinese voice-to-text (hold-to-talk)
- Command tools: clipboard, favorites, presets, recent
- @Mention system with notifications
- Local chat log saving (JSONL)
- Visual chat HUD editor with live preview
- Drag-to-move and resize chat HUD
- Customizable: font size, spacing, opacity, colors, backgrounds
- Mod Menu integration

## Installation

1. Install Fabric Loader 0.19.3+ for Minecraft 1.21.4
2. Install Fabric API 0.119.4+
3. Install owo-lib 0.12.20+
4. Drop `chat-canvas-1.2.0.jar` into your `mods` folder
