# Chat Canvas 1.3.0

Chat Canvas 1.3.0 for Minecraft 1.21.2 Fabric. This release reworks the voice
input system, expands the Emoji picker, and adds Traditional Chinese support.

## What's New

- **Reworked offline voice input**: four selectable speech models — sherpa-onnx
  streaming Zipformer Chinese (~30 MB, low resource), SenseVoice INT8
  (~240 MB, Mandarin/Cantonese/English/Japanese/Korean), Whisper Tiny INT8
  (~104 MB, multilingual) and the legacy Vosk small Chinese model (~44 MB).
  Models are downloaded only after you confirm, verified with SHA-256, and
  stored under `config/chatcanvas/voice-models/`.

- **VAD automatic endpoint detection**: Silero VAD detects speech and sentence
  end automatically. Press V to start voice input and press V again to finish
  manually. Configurable listen timeout, endpoint silence and tail padding.

- **Model manager**: pick, download, cancel, release and hot-swap speech models
  from the voice settings page — no game restart needed. Partial results are
  shown live while speaking; optional automatic punctuation.

- **Android / iOS compatibility layer**: platform detection for FCL /
  Pojav-class launchers with ARM64/ARM32 native runtimes. On iOS, the launcher
  must provide a signed sherpa-onnx runtime bridge. When the environment cannot
  support voice input, it is disabled safely and the rest of the mod keeps
  working.

- **Expanded Emoji picker**: 130+ emoji in 10 categories with a virtualized
  grid, tooltips, keyboard navigation and font-based filtering.

- **Traditional Chinese (zh_tw)** support.

- **Improved server interactive messages**: vanilla ClickEvent / HoverEvent
  interactions (run/suggest command, open URL, copy to clipboard, tooltips) are
  preserved inside the redesigned chat.

- **Responsive settings UI**: restyled editor panels and chat overlays,
  stabilized across GUI scales and aspect ratios.

## Voice Privacy

- Speech recognition runs **locally** once an offline model is installed.
- The microphone and decoding are active only during a voice session; audio is
  **never uploaded or saved**.
- Networking is used only for player-requested downloads (models and the
  sherpa-onnx native runtime); first voice setup requires an internet
  connection.

## Installation

1. Install Fabric Loader for Minecraft 1.21.2
2. Install Fabric API and owo-lib into `mods/`
3. Drop the Chat Canvas JAR into `mods/`
4. Launch the game — press K to open the editor

## Upgrading

Back up your configuration before upgrading. Existing config files should be
compatible; corrupted configs trigger an automatic backup and reset. If you
used voice input before, your settings are kept and the previous Vosk model
continues to work; the voice page now also offers the new models.

## Known Limitations

- Fabric 1.21.2 only; no Forge or NeoForge build.
- On iOS, voice input requires a launcher-provided sherpa-onnx runtime bridge;
  on Android it depends on the launcher exposing a microphone and native
  library loading.
- The legacy Vosk model only works on desktop x86-64.
- If a server plugin rewrites player messages into system messages, player
  colours and name quick actions may not work reliably.
- Emoji availability depends on the active font; unsupported glyphs are hidden
  automatically.
- Chat logs are plain local files: no built-in viewer and no cloud sync.

## 更新摘要（简体中文）

- **离线语音输入重构**：可选四套语音模型（Zipformer 中文流式 / SenseVoice 多语言 / Whisper Tiny 多语言 / Vosk 中文旧版），模型确认后下载、SHA-256 校验，存放于 `config/chatcanvas/voice-models/`。
- **VAD 自动断句**：按 V 开始，再按 V 结束；自动检测语音与句末，实时显示部分识别结果，可选自动句末标点。
- **模型管理器**：选择、下载、取消、释放、热切换模型，无需重启游戏。
- **Android / iOS 兼容层**：支持 FCL / Pojav 类启动器；iOS 需启动器提供 sherpa-onnx 运行库桥接，环境不支持时语音安全禁用。
- **Emoji 扩充**：130+ 表情、10 个分类、虚拟化网格与悬浮提示。
- **新增繁體中文（台灣）**。
- **服务器交互消息**：保留原版 ClickEvent / HoverEvent（执行/建议命令、打开链接、复制、悬浮提示）。
- **设置界面重构**：适配不同 GUI Scale 与屏幕比例。
