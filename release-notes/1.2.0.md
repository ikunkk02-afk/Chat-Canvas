# Chat Canvas 1.2.0

Chat Canvas 1.2.0 is the first full-feature release for Minecraft 1.21.5 Fabric.

## What's New

- **Dual chat channels**: Player chat and command/system messages are now
  displayed in two independently configurable channels with separate positions,
  text styles, and backgrounds.

- **Split player chat layout**: Classic single-column layout and a new
  left-right split layout that aligns your own messages to the right.

- **Command tools panel**: Recently executed commands, favourites, and
  clipboard integration with search, drag-to-reorder, and sensitive-command
  filtering. Click inserts at cursor — never auto-executes.

- **Unicode Emoji picker**: 10 categories, search, recent tracking, grapheme
  cluster-aware insertion. The emoji panel sits beside the input field.

- **Offline Chinese voice input**: Hold V (default) to speak, release to
  recognise. Powered by Vosk running entirely on your machine. No cloud, no
  upload, no recording.

- **Local chat log saving**: Automatically saves player messages to
  `.minecraft/chatcanvas/chat-logs/` in UTF-8 JSONL format, isolated per
  world/server, with daily rotation and retention control.

## Voice Privacy

- Voice recognition runs **completely offline** using Vosk.
- Audio is **never uploaded or saved** to disk.
- The Chinese model (~42 MB) is downloaded only after you explicitly confirm.

## Requirements

- Minecraft **1.21.5**
- Fabric Loader **0.19.3+**
- Fabric API **0.128.2+**
- owo-lib **0.12.21+**
- Java **21+**
- Mod Menu **13.0.2+** (optional)

## Installation

1. Install Fabric Loader for Minecraft 1.21.5
2. Install Fabric API and owo-lib into `mods/`
3. Drop the Chat Canvas JAR into `mods/`
4. Launch the game — press K to open the editor

## Upgrading

Back up your configuration before upgrading. Existing config files should be
compatible; corrupted configs trigger an automatic backup and reset.

## Known Limitations

- Only Fabric 1.21.5 is officially supported at this time.
- Voice recognition accuracy depends on microphone quality and ambient noise.
- Not all Unicode Emoji have glyphs in every resource pack.
- Other chat mods may require individual compatibility testing.
- Voice input is currently limited to player chat (not commands).
