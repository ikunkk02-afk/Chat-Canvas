# Chat Canvas

Chat Canvas（聊天画布）是一个适用于 Minecraft 1.21.1 的 Fabric 客户端模组。它提供可视化聊天框编辑器、艾特通知、玩家快捷操作、持久化命令剪贴板，以及聊天历史和输入框字间距配置。

所有功能都在客户端运行。命令剪贴板和玩家快捷操作只会修改聊天输入框，不会自动发送聊天消息或执行命令。

## 功能

### 聊天画布

- 自定义聊天框位置和尺寸
- 在编辑器中拖动聊天框并从八个方向缩放
- 自定义文字大小、行间距、字间距、透明度和阴影
- 左对齐、居中和右对齐
- 自定义消息背景、输入框背景和输入框边框
- 消息背景可跟随文字宽度或覆盖整行
- 保存、取消、撤销和重做

### 玩家名字与艾特

- 自动识别标准玩家消息，并为插件聊天提供备用识别
- 玩家名字自动配色和手动颜色覆盖
- 双击玩家名字，将 `@玩家名` 插入聊天输入框
- 艾特文本高亮
- 收到针对本地玩家的艾特时，可播放原版提示音、显示 Toast 或触发全屏闪烁
- 右键玩家名字可艾特玩家、填入私聊命令或复制玩家名
- 私聊模板支持 `/msg {player} `、`/tell {player} `、`/w {player} ` 等格式

### 命令剪贴板

- 在聊天输入框旁打开持久化命令面板
- 保存、搜索、分类、收藏、编辑、删除和重新排序命令
- 支持“全部”“收藏”“最近使用”和分类筛选
- 点击命令可替换输入框，或在当前光标/选区处插入
- 按住 Shift 点击可临时使用相反的插入方式
- 内置一组常用命令预设；预设只读，不写入用户命令文件
- 支持将预设另存到“我的命令”
- 对可能包含密码的命令显示明文存储警告
- 支持清除当前分类、清除非收藏命令或二次确认后清空全部命令

### 字间距

- 聊天历史和真实聊天输入框分别使用同一套字形推进测量
- 换行、左右/居中对齐、背景宽度、玩家名字命中、链接与悬停命中同步
- 输入框光标、选区、鼠标点击定位和水平滚动同步
- 支持中文、英文、Emoji、格式化文字和混合样式
- 字间距为 `0.0` 时使用原有快速路径

## 运行要求

- Minecraft `1.21.1`
- Java `21` 或更高版本
- Fabric Loader `0.19.3` 或更高版本
- Fabric API `0.116.14+1.21.1` 或更高兼容版本
- owo-lib `0.12.15.4+1.21` 或更高兼容版本
- Mod Menu `11.0.4` 或更高版本（可选）

## 安装

1. 安装适用于 Minecraft 1.21.1 的 Fabric Loader。
2. 将 Fabric API、owo-lib 和 Chat Canvas 的 JAR 放入 `.minecraft/mods`。
3. 启动游戏。

安装 Mod Menu 后，也可以从 Mod Menu 的配置按钮打开 Chat Canvas 编辑器。

## 使用

按 `K` 打开聊天画布编辑器。快捷键可以在 Minecraft 的“控制”设置中重新绑定。

在编辑器中：

- 拖动聊天框主体以移动位置。
- 拖动边缘或四角以调整尺寸。
- 在左侧分类中编辑布局、文字、背景、玩家颜色、艾特通知和命令输入设置。
- `Ctrl+Z` 撤销，`Ctrl+Y` 重做。
- 点击“保存”应用并持久化设置；点击“取消”或按 `Esc` 放弃本次编辑。

在真实聊天界面中：

- 双击玩家名字插入艾特。
- 右键玩家名字打开玩家快捷菜单。
- 点击输入框旁的“命令”按钮打开命令剪贴板。
- 命令条目只会填入输入框，不会自动发送。

## 配置与数据

主配置：

```text
config/chat_canvas.json
```

持久化用户命令：

```text
config/chat_canvas/command_clipboard.json
```

这两个文件都是全局客户端配置，不绑定世界或服务器。切换服务器、退出世界或重启游戏不会清空命令剪贴板。

命令剪贴板使用明文 JSON。保存 `/login`、`/register`、`/auth`、`/password` 等可能含密码的命令时，模组默认会再次警告。请不要在不受信任的设备上保存敏感命令。

## 兼容性

当前兼容目标：

- Chat Heads
- More Chat History
- ChatAnimation
- Smooth Scrolling

Chat Canvas 不实现聊天消息进入、滑入或滚动动画，可继续交由其他动画模组处理。兼容模组不是运行 Chat Canvas 的必需依赖。

## 开发

项目使用 Fabric Loom、Yarn 映射和 Java 21。

```powershell
.\gradlew.bat clean build
.\gradlew.bat runClient
.\gradlew.bat runClient -PwithModMenu=true
```

构建产物位于：

```text
build/libs/
```
